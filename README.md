# Elite Studio (desktop)

1. Create a new GitHub repository and upload everything in this folder (keep the `.github` folder).
2. Open the **Actions** tab. The build starts on every push (or press **Run workflow**).
3. When it finishes, open the run and download the artifact: `.exe` installer + portable for Windows, `.AppImage` for Linux, `.dmg` for macOS.

Run locally: `npm install` then `npm start`.

The desktop island overlay appears when you minimise the app (or switch away, see Extras > Dynamic Island > Desktop overlay).
